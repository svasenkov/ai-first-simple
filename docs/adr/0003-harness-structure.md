# 0003. Иерархия harness: роутер + rules + skills + kb + adr

Дата: 2026-09-21
Статус: принято

## Context

AI-агенту нужны инструкции проекта: команды, конвенции,
процедуры, справка. Простейший вариант — один большой
AGENTS.md, но тогда каждая сессия читает файл целиком: токены
тратятся на неактуальное (детали Jenkins нужны редко), файл
растёт и шумит.

## Decision

Иерархия с загрузкой по требованию:

- `AGENTS.md` — роутер ≤ 50 строк: только ссылки, без деталей;
- `.devin/rules/` — scoped-правила с `trigger: glob`,
  подгружаются при работе с файлами по паттерну;
- `.devin/skills/` — вызываемые процедуры (как добавить тест,
  как написать ADR);
- `docs/kb/` — база знаний «вопрос → ответ», вход — `INDEX.md`;
- `docs/adr/` — журнал решений (этот файл).

Агент читает только нужный файл по ссылке из роутера.

## Consequences

Экономия токенов и точечные обновления: факт живёт в одном
месте, правки не растягивают AGENTS.md. Цена — больше файлов
и дисциплина ссылок: роутер и `INDEX.md` должны оставаться
актуальными, иначе агент не найдёт нужное.
