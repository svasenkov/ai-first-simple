# 0004. Сначала GitHub Actions, Jenkins — в фазе 7

Дата: 2026-09-21
Статус: принято

## Context

Репозиторию нужен CI. Варианты:

- GitHub Actions — встроен в платформу, где уже живёт код;
- Jenkins — классика индустрии, но требует сервера; поднимать
  локальный Docker-стенд для учебного репо — лишняя
  инфраструктура для студента.

Без CI нет проверки PR, поэтому откладывать CI «до Jenkins»
нельзя.

## Decision

Первым — GitHub Actions (`.github/workflows/ci.yml`, фаза 2):
нулевая инфраструктура, триггеры push/PR в main, бейдж в
README, артефакт `allure-report` из коробки.

Jenkins — отдельной фазой 7 как демо self-hosted CI: тот же
прогон на готовом сервере **jenkins.qa.guru** (плагины Pipeline,
Allure уже стоят), без локального Docker — см.
`docs/kb/jenkins.md`. Канонический список шагов — ci.yml,
Jenkinsfile обязан их повторять.

## Consequences

CI появился сразу и бесплатно; студент видит и облачный, и
(self-hosted) CI. Цена — позже два конфига: Jenkinsfile
не должен расходиться с ci.yml. Jenkins-опыт отложен до
фазы 7, но будет на реальном сервере, а не в локальной
песочнице.
