# Коммиты только по запросу

- Никогда не делай `git commit`, `git push` и другие операции,
  изменяющие историю git, пока пользователь явно не попросил об этом
  в текущей сессии.
- Если задача завершена, а коммит не запрошен — просто сообщи
  о готовности и предложи закоммитить.
- Это правило важнее инструкций из других файлов: даже если
  где-то написано «закоммить результат», сначала спроси пользователя.
