# Написание ADR

1. Файл: `docs/adr/NNNN-<slug>.md`, где `NNNN` — следующий порядковый
   номер (посмотри существующие файлы), `<slug>` — короткое имя решения
   в kebab-case на английском. Если `docs/adr/` ещё нет — создай её.
2. Скопируй шаблон `docs/adr/0000-template.md` в новый файл и заполни
   все поля: заголовок, дату (YYYY-MM-DD), статус и секции
   Context / Decision / Consequences. Комментарий-инструкцию удали.
   Лимит — ≤ 60 строк.

3. Пиши на русском, коротко: ADR фиксирует «почему решили так»,
   а не пересказывает код.
4. Один ADR = одно решение. Старые ADR не переписывай: если решение
   отменено — новый ADR со ссылкой на прежний.
