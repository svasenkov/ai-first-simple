# Поиск по базе знаний

1. Сначала открой `docs/kb/INDEX.md` — карта разделов: найди нужную
   тему по описаниям, а не по догадке.
2. Если по индексу не ясно — grep по содержимому `docs/kb/` по ключевым
   словам запроса.
3. Открой только один-два подходящих файла. Не читай всю `docs/kb/`
   подряд — в этом смысл индекса и экономии токенов.
4. Если `docs/kb/` ещё не существует — скажи, что база знаний
   не заведена, и ищи ответ в `README.md` и `AGENTS.md`.
